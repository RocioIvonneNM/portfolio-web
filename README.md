# Rocío Ivonne — Portfolio 🌼

A bright, creative developer portfolio built with **Next.js 16**, **TypeScript**, and **Tailwind CSS 4**.

## Run locally

```bash
npm install
npm run dev
```

Visit http://localhost:3000.

## Quality checks

```bash
npm run lint
npm run build
```

## Structure

- `src/app/page.tsx` — home page
- `src/components/` — modular portfolio sections
- `src/data/portfolio.ts` — editable project, experience, and skills content
- `src/app/projects/[slug]/page.tsx` — individual project case studies

## Notes

Professional work is described as **case studies**, not public source repositories. Add screenshots, live demo links, a CV, and contact information only when you have approved materials to publish.
